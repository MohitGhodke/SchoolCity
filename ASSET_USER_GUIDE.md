# Asset System User Guide

## Quick Start

### Opening the Asset Menu
1. Look for the **"Assets"** button in the top-right corner of the screen
2. Click the button to open the asset selector menu
3. The menu will slide in with available asset categories

### Selecting and Placing Assets

#### Step 1: Choose a Category
- Click on **"Roads"** or **"Trees"** tab at the top of the asset menu
- Each category shows all available assets in that category

#### Step 2: Select an Asset
- Click on any asset from the grid
- The selected asset will be highlighted with a blue border
- The asset name will be displayed

#### Step 3: Place on Map
- **Single Click**: Place one asset at a time
- **Click and Drag**: Place multiple assets by dragging across tiles
- Selected asset will appear on the map where you click

### Removing Assets

#### Using Erase Mode
1. Click the **"Erase Asset"** button at the bottom of the asset menu
2. The button will turn red when active
3. Click or drag over assets to remove them
4. Click "Erase Asset" again to exit erase mode

#### Using Clear Selection
- Click **"Clear Selection"** to deactivate asset mode
- Returns to normal pan/navigation mode

### Asset Placement Rules

✅ **You CAN:**
- Place assets on any tile (municipal, area, unit, or beat tiles)
- Place different types of assets next to each other
- Remove and replace assets as many times as you want
- Save and load your asset placements

❌ **You CANNOT:**
- Place an asset where another asset already exists
- Place assets outside the grid boundaries
- Place assets on top of schools (schools take precedence)

## Tips and Tricks

### Creating Road Networks
1. Start with straight roads to connect areas
2. Use corners to turn roads
3. Add T-junctions where roads meet
4. Use crossroads for major intersections

### Landscaping with Trees
1. Place trees along roads for tree-lined streets
2. Create parks by clustering trees
3. Mix different tree types for variety
4. Use trees to separate different zones

### Efficient Workflow
1. Plan your layout before placing assets
2. Use drag-to-place for long roads
3. Switch between categories using the tabs
4. Use pan mode to navigate while planning
5. Save your game frequently to preserve your work

### Keyboard and Mouse
- **Left Click**: Place asset or navigate (in pan mode)
- **Click + Drag**: Place multiple assets or pan the view
- **Mouse Wheel**: Zoom in/out (works in any mode)

## Integration with Game Features

### Saving and Loading
- All placed assets are automatically saved when you click "Save Game"
- Assets are restored when you load a saved game
- Use "Clean Slate" to remove all assets and start fresh

### Boundaries and Assets
- Assets are independent of boundaries (municipal/area/unit)
- You can place assets across different boundary types
- Boundaries can be changed without affecting assets
- Assets remain when you repaint boundaries

### Schools and Assets
- Assets cannot overlap with schools
- Schools take priority over assets
- Place schools first, then add surrounding assets
- Remove assets before placing schools in that location

## Troubleshooting

### Can't Place Asset
**Problem**: Clicking doesn't place the asset
**Solutions**:
- Check if an asset already exists at that location
- Verify you have an asset selected (highlighted in blue)
- Make sure you're not in pan mode
- Ensure the position is within the grid boundaries

### Asset Menu Not Opening
**Problem**: Assets button doesn't work
**Solutions**:
- Refresh the page
- Check browser console for errors
- Try zooming in/out and clicking again

### Assets Not Saving
**Problem**: Assets disappear after reload
**Solutions**:
- Click "Save Game" button before closing
- Check browser localStorage is enabled
- Verify you're using a supported browser

### Erase Mode Stuck
**Problem**: Can't exit erase mode
**Solutions**:
- Click "Erase Asset" button again to toggle off
- Click "Clear Selection" to exit all modes
- Click any asset to switch to placement mode

## Advanced Usage

### Creating Complex Road Systems
Example: Building a grid-style city
```
1. Place horizontal straight roads every 3-4 tiles
2. Place vertical straight roads every 3-4 tiles
3. Use crossroads at all intersections
4. Add T-junctions for road branches
```

### Thematic Landscaping
Example: Creating a park district
```
1. Paint a unit boundary for the park area
2. Fill the area with various tree types
3. Add paths using horizontal/vertical roads
4. Place a school in or near the park
```

### Mixed Development
Example: Suburban neighborhood
```
1. Create winding roads with corners
2. Place trees along one side of roads
3. Position schools at strategic locations
4. Fill remaining spaces with trees for green spaces
```
